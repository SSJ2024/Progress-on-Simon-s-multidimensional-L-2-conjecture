# Paper I

**Simon's Multidimensional \(L^2\) Conjecture and the Failure of
Fixed-Potential Selected-Channel Entropy: Plücker-Schur Reductions and a
Reciprocal Riesz-Talbot Construction**

The source is split between `main.tex` and
`fixed_potential_riesz_counterexample.tex`. Compile `main.tex`; the second
file is included automatically near the end of the manuscript.

The principal claim concerns failure of a fixed selected-channel entropy
estimate. It is not a counterexample to Simon's multidimensional \(L^2\)
conjecture.

The distributed PDF was built with Tectonic 0.16.9.
