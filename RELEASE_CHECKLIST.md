# Release and submission checklist

## Mathematical audit

- [ ] Independent specialist review of the main theorem in Paper I.
- [ ] Independent review of the reciprocal Riesz cell and uniform lacunary
      placement arguments.
- [ ] Independent review of the operator-valued contraction theorem in
      Paper II.
- [ ] Confirm that every conditional use of the short-time radial compiler is
      visibly labelled.
- [ ] Recheck the exterior/full-space scattering bridge if the open
      radialization problem is later solved.

## Manuscript audit

- [x] Author name and email included.
- [x] Concise abstracts, keywords, and 2020 MSC codes included.
- [x] Simon's conjecture described as open.
- [x] LaTeX sources compile without unresolved references.
- [x] Final PDFs visually inspected.
- [ ] Adapt to the selected journal's class and bibliography style.
- [ ] Professional copy-edit of both long manuscripts.

## Repository audit

- [x] Project-owned source, notes, and code included.
- [x] Downloaded third-party literature excluded.
- [x] Reproducibility scripts labelled as diagnostics.
- [ ] Choose licenses for manuscripts and code.
- [ ] Add repository URL, release tag, and archival DOI.
- [ ] Update `CITATION.cff` with the archival DOI.

## Public claim

Use: “counterexample to a fixed selected-channel entropy strategy” and
“operator-valued contraction with an open physical radialization step.”

Do not use: “proof of Simon's conjecture,” “disproof of Simon's conjecture,”
or “solution of the multidimensional \(L^2\) conjecture.”
