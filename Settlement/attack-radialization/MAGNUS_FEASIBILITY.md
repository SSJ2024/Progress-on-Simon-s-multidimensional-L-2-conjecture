## 0. The class constraint (the structural heart)

**Lemma 0.** If every mask is *simultaneously diagonal in the eigenbasis of Λ* — i.e.
each q_j lies in the algebra generated by {Y^ℓ_m : ℓ ≤ L} with the property
[M_q, Λ] = 0 on E's spectral span — then every word W_s is a function of Λ, hence
diagonal on E. It realizes e^{−isT f(Λ)} only; matching χ·e^{−isTτΛ} needs f(λ) ≡ τλ + c
on the finitely many eigenvalues λ ∈ spec(Λ)|_E.

Consequences.
- (a) On E = span{Y⁰₀, Y¹₋₁,Y¹₀,Y¹₁}: eigenvalues {0,2}. Need f(0)=c, f(2)=2τ+c:
  satisfiable by a DIAGONAL word! But then W_s acts as e^{−isc}·e^{−is(f(Λ)−c)} —
  still diagonal, so G(s)=e^{isτA_3}|_E IS realized on this E up to phase by a purely
  spectral word... **provided the required mask time-average is achievable within
  bounded height and the s-uniformity holds.** This is the degenerate-eigenspace
  escape hatch: for two-point spectra any monotone interpolation works.
- (b) For three or more distinct eigenvalues {λ_a}, f must match τλ+c at ≥3 points;
  a quadratic f can do it if the points are in "quadratic position" — but f comes from
  time-averages of bounded masks plus commutator corrections (below), so the real
  constraint is quantitative, not qualitative.
- (c) The genuine obstruction class: targets G that are NOT functions of Λ (e.g.
  arbitrary continuous unitaries from thm l. 6189, or transpositions). Diagonal words
  never leave the conjugacy orbit of diagonal matrices. Mixing between eigenspaces
  REQUIRES [M_u-integral, Λ] ≠ 0 masks — off-diagonal coupling to complementary modes,
  i.e. leakage-generating excursions that must refocus (prop:no-exact-scalar-galerkin-mixer).

So: the lens target e^{isτA_3}|_E is *inside* the diagonal class. The whole difficulty
of prob:short-time-radial-compiler for the lens instance reduces to: **can bounded,
cheap, short-total-time masks shift the effective spectral function from λ to f(λ)=τλ
across spec(Λ)|_E?** That is exactly an AC-Stark / rotating-wave renormalization
question. Orders 2–3 decide it.

## 1. Order 1

Ω₁(T) = −iT Λ − i∫₀ᵀ V(t)dt = −iT[Λ + q̄], q̄ := T^{−1}∫q.
Tracking e^{−iτTΛ} forces, mod scalars, Λ + q̄ = τΛ on E, i.e.

    q̄|_{spec(E)} = (τ−1)Λ|_{spec(E)}.                                   (O1)

Zero-mean static masks give q̄=0: nothing at order 1. With q̄ ≠ 0 you need
‖q̄‖_∞ ≥ (τ−1)·min|λ| over the used eigenvalues — amplitude grows linearly in (τ−1)
but NOT in 1/η: order 1 alone does not force long time. However q̄ ≠ 0 means a nonzero
DC mask: its X_3 cost is T^{−1}‖T q̄‖²/T = ‖q̄‖² ≥ ((τ−1)λ_min)² > 0 — bounded away
from zero, violating "arbitrarily small charged cost" only if we insist cost→0 while
τ−1 fixed. Note the problem demands Σt_j < η AND small cost simultaneously; a DC mask
of fixed size held for vanishing time has vanishing effect — order 1 tracking FAILS as
T→0 unless q̄ ~ (τ−1)Λ independent of T, i.e. amplitude FIXED (fine: bounded height!)
and cost ‖q̄‖²·(1/T per slab normalization)... careful: cost of one slab carrying
integrated mask w=Tq̄ is T^{−1}‖w‖² = T‖q̄‖² → 0 as T→0. **Order-1 DC renormalization
is cheap and short**: hold constant mask q̄=(τ−1)Λ̃ (any bounded function equal to
(τ−1)λ on eigenspace E_λ). Cost → 0 like T. Height bounded by |τ−1|·max|λ|.

Why is this not the end? Because q̄ must be a FUNCTION ON S² constant on each eigenspace
of Λ but taking DIFFERENT values on different eigenspaces. Such a function exists iff
the eigenspaces' angular supports allow a smooth interpolant: for E=span{Y⁰₀,Y¹ₘ},
need q̄=c₀ on Y⁰₀-support and q̄=2(τ−1)+c₀ on Y¹-supports. Y¹ spans all of ℝ³-directions;
Y⁰₀ is spread everywhere. A bounded smooth function CAN approximate different constants
on the Y⁰₀ and Y¹ sectors only weakly (they overlap in space!). Concretely: take
q̄ = α + β z (z=cosθ): ⟨Y⁰₀,q̄⟩=α, ⟨Y¹ₘ,q̄ Y¹ₘ⟩-matrix = β⟨z Y¹ₘ,Y¹ₘ'⟩ + αδ. z couples
ℓ=0↔ℓ=1 diagonally? No: ⟨Y¹ₘ, z Y¹ₘ⟩ ≠ 0 (z preserves m, mixes ℓ=1 with ℓ'=1? —
z Y¹ₘ ∈ span{Y⁰ₘ,Y²ₘ}; the ℓ=1 component survives: coefficient ⟨Y¹ₘ,zY¹ₘ⟩ =
∫z|Y¹ₘ|² ≠ 0). So YES: q̄=α+βz gives distinct effective shifts on ℓ=0 vs ℓ=1 blocks
at order 1 — but it also has OFF-DIAGONAL parts (z mixes Y⁰↔Y¹? ⟨Y⁰₀,zY¹₀⟩≠0 yes).
Those off-diagonal pieces drive leakage into/out of E — second-order treatment below.

## 2. Interaction picture and order 2 (the Lamb-shift mechanism)

Move to the frame of the FREE flow (we track e^{−iτTΛ}, so use frame of e^{−itΛ}):

    Ṽ_I(t) = e^{itΛ_ad}V(t)e^{−itΛ_ad},   Λ_ad := full A_3 (acting on L²(S²)).

Magnus in interaction picture:
    Ω(T) = Ω₁ + Ω₂ + Ω₃ + …,
    Ω₁ = −i∫V_I,
    Ω₂ = −½[i]∫₀ᵀdt₁∫₀^{t₁}dt₂ [V_I(t₁),V_I(t₂)]  (standard sign conventions),
    Ω₃ = −(i/6)(∑[[V,V],V]-terms) etc.

Split V = D(t) + O(t): D := part commuting with Λ_ad (diagonal-in-ℓ,m masks, e.g.
functions of φ only, or zonal pieces acting diagonally on the chosen block), O := the
rest ([M_O, Λ_ad] ≠ 0).

**Key exact fact (as flagged in the task):** for multiplication operators,
[M_u, Λ_ad] is a FIRST-ORDER differential operator (commutator of multiplication with
Laplacian = 2∇u·∇ + Δu). Hence on EXACT eigenspaces of A_3, [V_I(t₁),V_I(t₂)] has:
 - D–D part: 0 (they commute);
 - D–O/O–D parts: oscillatory factors e^{±i(λ_a−λ_b)t} times first-order operators
   COUPLING different eigenspaces — these average out under fast modulation unless
   near-resonant;
 - O–O parts: products of first-order operators ⇒ SECOND-order operators; their time
   integrals carry denominators (λ_a−λ_b)^{−1} from integrating the phases, giving
   per-pair SCALAR-like shifts on each eigenspace pair — the Lamb-shift structure.

Effective order-2 operator on E (degenerate perturbation theory / RWA):

    H_eff^(2) = Λ + q̄ + Σ_{b∉used or b∈used} (something)/Δ_ab  acting within E,

where each term is a polynomial in the projectors P_a onto eigenspaces — i.e. a
FUNCTION OF Λ ON E (scalar per eigenspace), PLUS genuinely off-block pieces when
masks couple E to itself non-diagonally through intermediate complementary modes.

**Can order-2 simulate τ·λ?** Write the desired correction δH := (τ−1)Λ|_E =
Σ_a (τ−1)λ_a P_a. Order 2 produces exactly terms of the form Σ_a μ_a P_a (per-eigenspace
scalars) whenever the O–O commutator integrals act within-block-diagonally. So YES at
the level of FORM: any assignment {μ_a = (τ−1)λ_a} is a valid target for the
second-order self-energy. Two questions: magnitude and sign control.

Magnitude: standard second-order shift |μ_a| ≲ Σ_b ‖O_ab‖²/Δ_ab where Δ_ab is a gap
between eigenvalues of Λ (NOT of the driven system) and ‖O_ab‖ ≤ ‖∇u‖_{L²-coupling}
≲ ‖u‖_{W^{1,∞}} ≤ Q·D (height × angular degree). To reach μ_a = (τ−1)λ_a with gaps Δ
FIXED by the sphere (Δ = |λ_a−λ_b| = O(1)), we need ‖O‖² ∼ (τ−1)λ_a Δ — i.e. amplitude
∼ sqrt((τ−1)Δ) — BOUNDED, no 1/T blowup. Time-dependence enters only through the
phase integration ∫₀ᵀ∫₀^{t₁} e^{iΔ(t₂−t₁)} dt₂dt₁ = T − sin(ΔT)/Δ etc.: for T ≫ 1/Δ
this saturates to T·(πδ(Δ)-type resonant pieces + principal value); for our regime
T < η → 0, the kernel → T²/2 · 1 (phases frozen!), giving

    Ω₂ ≈ −(i T²/4)[V̄₁-type double integrals] — QUADRATIC IN T.

**This is the crux.** In the frozen-phase regime T≪1/Δ, ALL order-2 self-energies scale
like T², while the TARGET correction scales like T (we need Ω ≈ −iτTΛ, difference from
free flow −iTΛ is −i(τ−1)TΛ = O(T)). Matching O(T) targets with O(T²) mechanisms fails
as T→0 UNLESS amplitudes grow like 1/√T — forbidden by bounded height.

Wait — check the resonant loophole: denominators Δ are fixed, but if the mask is made
FAST-MODULATED at frequency ω (carrier), the interaction-picture phases become
e^{i(Δ±ω)t} and the effective kernel becomes resonant: for ω ≈ −Δ, the integral
grows like T (not T²) with numerator ‖O‖²/Δ_res. THIS is the standard RWA
renormalization: a bounded-amplitude carrier at frequency ω≈gap produces an O(T)
effective Hamiltonian term of size ‖O‖²/(ω+Δ). So:

**Order-2 verdict:** per-eigenspace scalar shifts of size (τ−1)λ_a ARE producible with
BoundedHeight via a carrier at frequency matched to a gap, PROVIDED:
 (i) some gap Δ_ab with |Δ_ab| ≍ |τ−1||λ_a| exists among modes the masks couple
     (true for ℓ=0 vs ℓ=1: Δ=2);
 (ii) the carrier itself costs NO A_3-time (it doesn't: modulation lives inside slab
     profiles w_j(x) = q(x)cos(ω x/T)? — CAREFUL: slabs are spatial masks at frozen
     radius; temporal carrier = alternating mask signs across sub-slabs, each sub-slab
     pays cost ‖w_j‖²/T_j; splitting w into ±alternating halves keeps Σcost = Cauchy-
     Schwarz-bounded BELOW by ‖∫w‖²/ΣT_j — the DC part is what the floor sees;
     the AC part's cost is EXTRA but also →0 like its own integrated profile).
 (iii) The resonant denominator is tuned: ω+Δ = O((τ−1)) gives μ = ‖O‖²/(ω+Δ) large —
     but detuning precision needed is |δω| ≲ 1/T → as η→0 the resonance WINDOW widens
     (good!) while selectivity against OTHER pairs worsens (leakage risk).

## 3. Order 2 on the minimal model: explicit computation

Model: E = span{Y⁰₀ ≡ |0⟩, Y¹₀ ≡ |1⟩} (m=0 slice; full ℓ=1 handled identically by
SO(3) covariance). Λ = diag(0,2). Mask ansatz u(t) = a·cos(ωt)·z(x) + d(t)·z(x) with
z = cosθ. Couplings: z|0⟩ = c₁|1⟩ + c₂|2⟩ with c₁ = ⟨Y¹₀,zY⁰₀⟩ = 1/√3, and the rest
goes to ℓ=2 (complementary — leakage channel, suppressed by RWA at ω≈2).
Within-E: z has matrix element ⟨1|z|0⟩ = 1/√3; diagonal elements ⟨a|z|a⟩ = 0 for
ℓ=0,1 (parity!). So z is purely off-diagonal on E: an ideal RWA coupler.

RWA at ω = −2 + δ (driving the |0⟩↔|1⟩ transition resonantly): effective Hamiltonian
in rotating frame: H_eff = [[0, a c₁/2], [a c₁/2, −δ]] + Stark shifts
a²(c₁²/4)/(ω−Δ_other) on each level. On resonance δ=0, evolution time T:
U ≈ exp(−i (ac₁/2) σ_x T) — a MIXER, not a phase shifter. For pure phase
renormalization (diagonal target) we instead need the STARK part: detune far enough
that populations stay put but acquire shifted phases: μ_a = a²c₁²/(4(ω∓Δ)).
Choose two carriers ω₁≈−Δ₀₁+ν, ω₂≈−Δ₀₁−ν': μ₀−μ₁ = a²c₁²(1/(4(ω₁−Δ…)))… — the point:
DIAGONAL renormalization μ₀−μ₁ = 2(τ−1) achievable with a = O(sqrt(|τ−1|·Δ)) BOUNDED,
via far-detuned Stark (no population transfer), OR via near-resonant dressing followed
by adiabatic elimination of the dressed state — both are textbook.

**But here is the catch the frozen-phase computation exposes:** Stark shifts from a
STATIC far-detuned field accumulate as ∫a²dt /(Δ) = a²T/Δ = O(T) — good, linear in T,
amplitude bounded. So static detuned masks DO give O(T) diagonal renormalization!
Re-examine §2's pessimism: that applied to the O–O COMMUTATOR (nonlinear) piece with
zero-mean fast modulation. A plain DC-detuned mask q̄ = μ·(level-dependent) is just the
order-1 mechanism again — and its limitation is the SPATIAL one: no smooth function is
exactly constant-on-{0,2}-eigenspaces with prescribed split values while having zero
cross-matrix elements. The cross-matrix element ⟨0|q̄|1⟩ ≠ 0 leaks. Order 2 (or a
counter-rotating echo) cancels the leak; the price is the O–O commutator term — which
is O(T²)·(couplings)² and thus harmless as T→0!

**Emergent clean statement:**
    Ω(T) = −iT[Λ + Q̄] + O(T² · ‖Q̄‖²-offdiag-stuff) + O(T³),
where Q̄ = T^{−1}∫u. Choose bounded Q̄ approximating the spectral multiplier (τ−1)Λ + c
ON E up to off-diagonal residual ρ with ‖ρ‖ ≤ ρ_max. Then
    ||U(T) − e^{−iT(Λ+Q̄+c)}|| ≤ C T² (‖Q̄‖² + ‖[Q̄,Λ]‖-type terms).
The diagonal part of Q̄ delivers EXACTLY τΛ-tracking; the off-diagonal residue causes
error O(T²‖Q̄‖²ρ-ish) — VANISHING as T→0 without any amplitude growth. The s-uniformity
is automatic since everything is s-linear.

So the REAL questions reduce to approximation theory: how well can a bounded smooth
mask's compression operator (compression P_E M_Q̄ P_E) approximate τΛ + scalar on a
GIVEN E, and what does the off-diagonal residue do at order 2–3?

## 4. Order 3 sanity check

Ω₃ involves [[V_I,V_I],V_I] integrals: triple integrals of nested commutators of
first-order operators. Scaling: each extra V brings a factor ‖Q̄‖T (frozen phases), so
Ω₃ = O(T³‖Q̄‖³) — negligible. The dangerous order-3 effects are RESONANT ones (secular
terms growing like T when carrier frequencies hit 2-photon resonances ω ≈ −(λ_a−λ_c)/2):
two-photon transitions between E-levels would create NON-diagonal contamination at
O(a²T) — same size as the wanted Stark shift! Avoidance: keep 2-photon detunings
|2ω+λ_a−λ_c| ≫ a² — a spectral-position condition on E, generically satisfiable
(tune ω to serve the 1-photon Stark denominators but miss half-gap resonances).
For E = {ℓ=0,ℓ=1}: 2-photon resonance needs 2ω = ±2; Stark-serving ω satisfies
|ω| ≫ a·c₁ — choose ω = 3 (say): then |2ω+Δ|=4 or 8 ≫ a². Fine.

## 6. Where the audited no-gos bite, precisely

  content D_τ ~ 1/τ triggers the D²T/R² ledger. Our route uses NO large-gradient phase
  masks: masks stay O(h) in C¹ norm (carrier amplitudes bounded, degrees FIXED = the

  i.e., assumes the twist-conjugation architecture. Different mechanism, different
  integrated-profile budget.

  bounded smooth functions, NOT near-unit-modulus oscillatory phases; ‖w_τ‖ stays O(h·T)
  → 0. The proposition explicitly says: "does not exclude a different diffractive
